## Uso en El Reino de los 33
La grabación se incluye como **música de fondo**, activada voluntariamente por el visitante. 
Este archivo se distribuye a través de GitHub Pages y se utiliza sin fines comerciales.
No hay reproducción automática; la reproducción se detiene al cambiar de pestaña.

Crédito visible en la invitación:

> Música: «Wonder6» — PeriTune · CC BY 4.0.

El enlace del título va al origen; la licencia también va enlazada.

## Archivos
- `assets/peritune-wonder6.mp3` — MP3 extraído del sitio web oficial de PeriTune, verificado por GitHub Actions antes de publicarse.
- `scripts/descargar_wonder6.py` — receta reproducible de descarga y verificación desde el dominio oficial.
- `.github/workflows/descargar-wonder6.yml` — solo activado en la rama de integración.

## Cambios y transparencia
Si se elige el archivo «loop» oficial, se usa la versión de bucle suministrada por el propio compositor, sin mezclar ni reorquestar la música.
Si se selecciona la versión MP3 normal, se reproduce como archivo original en bucle por el reproductor HTML5, sin modificar los datos musicales. El navegador puede hacer una breve pausa entre ciclos.
Se ajusta **solo el nivel de volumen de reproducción** del usuario, sin alterar el archivo.
La versión anterior compuesta para la invitación sigue disponible en el repositorio como respaldo.
